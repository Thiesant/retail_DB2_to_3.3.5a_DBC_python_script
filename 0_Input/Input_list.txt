Required Files for 0_Input Directory
═══════════════════════════════════════════════════════════════

1. LISTFILE (REQUIRED)
───────────────────────────────────────────────────────────────
Filename: Any file containing "listfile" (case-insensitive)
Format: FileDataID;FilePath (semicolon-separated)
Source: https://github.com/wowdev/wow-listfile


2. RETAIL DB2 TABLES (CSV format: [table].csv or [table].[version].csv)
───────────────────────────────────────────────────────────────
Source: https://wago.tools/db2

  - CreatureDisplayInfo.csv
  - CreatureDisplayInfoGeosetData.csv
  - CreatureModelData.csv

  - FootstepTerrainLookup.csv

  - GameObjectDisplayInfoXSoundKit.csv
  - NPCSounds.csv
  - ObjectEffect.csv
