# CSV_to_DBC.py - Binary DBC Converter Documentation

## Description
This Python script converts CSV database files to DBC for World of Warcraft 3.3.5a.

**This tool is optional if you don't want to manually import the csv with WDBX Editor** - CSV files alone cannot be used by the WoW client.

## Purpose

The CSV_to_DBC converter serves as the bridge between human-readable CSV files and game-ready binary DBC files:

- **Creates .dbc files** from CSV data
- **Merges with existing DBCs** (preserves original WotLK data)
- **Updates only specified records** (non-destructive)
- **Automatic backup creation** (saves .dbc.bak files)
- **Sorted output by ID** (maintains proper structure)

### Setup Directory Structure
```
/
├── CSV_to_DBC.py
├── 2_DBCRetail_to_Wotlk_csv/           # Output from DB2_to_DBC.py
│   └── [Table].csv                     # CSV files to convert
├── 3_DBC_Filtered/                     # Output from DB2_to_DBC_Filtered.py
│   └── [Table].csv                     # CSV files to convert
└── 6_DBC_Binary/
    └── DBFilesClient/                  # WoW DBC files (input/output)
        ├── [Table].dbc                 # Existing WotLK DBCs (optional)
        └── [Table].dbc.bak             # Auto-created backups
```

The script requires:

#### 1. `2_DBCRetail_to_Wotlk_csv/` OR `3_DBC_Filtered/` - CSV Source (Required)
Must contain one or more CSV files generated by:
- **DB2_to_DBC.py** (full conversion) - outputs to `2_DBCRetail_to_Wotlk_csv/`
- **DB2_to_DBC_Filtered.py** (filtered models) - outputs to `3_DBC_Filtered/`

**Note**: If both directories exist, the script will ask which one to use.

#### 2. `6_DBC_Binary/DBFilesClient/` - DBC Directory (Auto-created)
- This directory will be **automatically created** if it doesn't exist
- **Optional**: Place existing WotLK DBC files here to merge with new data
- **Without existing DBCs**: Script creates new files from scratch
- **With existing DBCs**: Script updates/adds records while preserving original data

## How to Use

### Related Tools

**Complete Workflow:**
1. **[m2_Hardcoded_SoundEntry_ID_extractor.py](M2_Sound_Events_Extractor_README.md)** - Extract M2 sounds (optional but recommended)
2. **[DB2_to_DBC.py](DB2_to_DBC_README.md)** - Full conversion to CSV,
   OR
   **[DB2_to_DBC_Filtered.py](DB2_to_DBC_Filtered_README.md)** - Filtered conversion to CSV
3. **CSV_to_DBC.py** - **This tool** - Convert CSV to DBC

### 1. Prepare Input Files

**Option A: From Full Conversion**
```bash
# Run full DB2 to CSV converter first
python DB2_to_DBC.py
```
This creates CSV files in `2_DBCRetail_to_Wotlk_csv/`

**Option B: From Filtered Conversion**
```bash
# Run filtered DB2 to CSV converter first
python DB2_to_DBC_Filtered.py
```
This creates CSV files in `3_DBC_Filtered/`

**Optional: Add Existing WotLK DBCs**
- Place your original WotLK DBC files in `6_DBC_Binary/DBFilesClient/`
- Script will merge new data with existing entries
- Original data is preserved for all non-updated IDs

### 2. Run the Script

Open terminal in the script's folder and run:

```bash
python CSV_to_DBC.py
```

### 3. Interactive Prompts

#### If Multiple CSV Sources Found:
```

  [1] 2_DBCRetail_to_Wotlk_csv/ (22 table(s))

Select CSV source [1-2]:
```

- **Option 1**: Use full conversion output (all 22 tables)
- **Option 2**: Use filtered conversion output (up to 14 tables)

#### Confirmation Prompt:

The script will:

3. **Merge** CSV data with existing records
4. **Create backups** (.dbc.bak) of original files
5. **Write** updated binary DBC files
6. **Display** detailed statistics per table

### Backup Files

- **Filename format**: `[Table].dbc.bak`
- **Created automatically** when updating existing DBCs
- **Contains**: Exact copy of the original DBC before modification
- **Purpose**: Safety net for reverting changes

## Troubleshooting

### Common Issues

#### "Creating DBC directory: 6_DBC_Binary/DBFilesClient"
This is **normal** on first run:
- Directory is auto-created
- You can now place existing WotLK DBCs here
- Re-run the script to merge with existing files

#### "No CSV files found in: [directory]"
**Solution**: Run the CSV generator first:
- **Full conversion**: `python DB2_to_DBC.py`
- **Filtered conversion**: `python DB2_to_DBC_Filtered.py`

#### "ERROR: No schema defined for [Table]"
The script only supports the 22 tables listed above. If you need additional tables, the schema must be added to the script.

#### "WARNING: Could not read existing DBC"
Possible causes:
- DBC file is corrupted
- File is from wrong WoW version (not 3.3.5a)
- File has incompatible format
- Insufficient read permissions

**Solution**: Remove or rename the problematic DBC file, then re-run.

#### "WARNING: Could not create backup"
Usually a permissions issue:
- Check write permissions in DBC directory
- Close any programs that might have the file open (WDBX Editor, etc.)

#### Backup Files Accumulating
Each run creates `.bak` files. You can:
- Delete old backups after confirming conversion worked
- Keep the most recent backup for safety
- Ignore them (they're not loaded by the game)

### Installation to Game

After conversion:

1. **Locate your WoW 3.3.5a installation**
2. **Navigate to**: `World of Warcraft/Data/`
3. **Copy the entire** `DBFilesClient/` folder from `6_DBC_Binary/` (except .bak)
4. **Overwrite** when prompted (or merge carefully)
5. **Test in-game**

**Recommended**: Always keep backups of your original game DBCs before overwriting.
